Диаграмма классов — срисовывай как образец одногруппника
=======================================================
Готовый рисунок: docs/class-diagram.png
Вставь его в РПЗ как «Рисунок 2 — Диаграмма классов».
Если нужен StarUML — повтори этот вид один в один.


ПАКЕТ «Фронтенд» (вкладка сверху слева пустая, имя пакета по центру)
Четыре Class, у каждого ТРИ полоски: имя / пусто / пусто.
Имя в две строки. Операций и атрибутов НЕТ.

  Страница          Страница             Страница          Страница
  Лента             Добавление           Плитка            Авторизация

Первая и третья чуть выше, вторая и четвёртая чуть ниже.


МЕЖДУ ПАКЕТАМИ — два кружка Interface (lollipop), не прямоугольники:

  API dendro_scale_patterns (o)     (o) API dendro_researchers

Лента, Добавление, Плитка  ——прямая——>  кружок паттернов
Авторизация                ——прямая——>  кружок исследователей
От кружка вниз в свой домен (сплошная).


ПАКЕТ «Бэкенд»
Два Class с ТРЕМЯ полосками: имя / пустая / методы.

Домен dendro_scale_patterns
  + GET /api/dendro_scale_patterns()
  + GET /api/dendro_scale_patterns/feed()
  + GET /api/dendro_scale_patterns/draft()
  + POST /api/dendro_scale_patterns()
  + PUT /api/dendro_scale_patterns/publish()
  + DELETE /api/dendro_scale_patterns/:id()
  + POST /api/dendro_scale_patterns/:id/like()

Домен dendro_researchers
  + POST /api/dendro_researchers/register()
  + POST /api/dendro_researchers/login()
  + POST /api/dendro_researchers/logout()


ПАКЕТ «Модель»
Три Class, три пустые полоски, только имя:
  DendroScalePattern    DendroPatternLike    DendroResearcher
Пунктир со стрелкой от домена паттернов к Pattern и Like,
от домена исследователей к Researcher.


ПАКЕТ «База данных»
Три простых прямоугольника (без полосок), только имя:
  dendro_scale_patterns    dendro_pattern_likes    dendro_researchers
Пунктир модель → таблица.
Между таблицами сплошные ассоциации:
  patterns  0..* —— 0..*  likes  0..* —— 1  researchers
  снизу: patterns  0..* ————— 1  researchers
