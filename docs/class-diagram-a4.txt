Диаграмма классов Dendro Age — как на примере с Postman
=======================================================
Лист А4, книжная ориентация. Шрифт 8 pt. Всё на одном листе.

Схема такая же, как на образце: сверху клиент, ниже веб-сервис
с доменами, ещё ниже модели, внизу таблицы БД.

================================================================
ЧТО РИСОВАТЬ В STARUML ПО СЛОЯМ
================================================================

1) Сверху класс Postman (клиент).

2) От Postman две стрелки вниз к интерфейсам (кружки / lollipop
   или класс со стереотипом <<interface>>):
     API DendroScalePatterns
     API DendroResearchers

3) Большой Package / Frame с названием «Веб-сервис».
   Внутри два класса-домена с двумя полосками (имя + операции).
   Методы пиши как в таблице ниже, с HTTP-глаголом.

4) Ниже Package «Модель»:
     DendroResearcher
     DendroScalePattern
     DendroPatternLike
   Пунктирные стрелки Dependency:
     Домен DendroScalePatterns --> DendroScalePattern
     Домен DendroScalePatterns --> DendroPatternLike
     Домен DendroResearchers   --> DendroResearcher

5) Внизу Package «База данных»:
     таблицы как классы <<table>> или ER Entity.
     Пунктир от модели к своей таблице.
     Между таблицами обычные связи FK, без подписей имён,
     без цифр 1 и * (по замечанию к ER).

6) Маленький Note у веб-сервиса:
     singleton Login() = shebe
     используется в draft, create, publish, like

  + GET    /api/dendro_scale_patterns/draft
  + POST   /api/dendro_scale_patterns
  + PUT    /api/dendro_scale_patterns/publish
  + DELETE /api/dendro_scale_patterns/:id
  + POST   /api/dendro_scale_patterns/:id/like

Домен DendroResearchers
  + POST /api/dendro_researchers/register
  + POST /api/dendro_researchers/login
  + POST /api/dendro_researchers/logout


================================================================
СТРАНИЦЫ SSR (если преподаватель просит 4 страницы на той же диаграмме)
================================================================
Отдельный маленький столбец слева от веб-сервиса, классы
с двумя полосками:

FeedPage
  openFeed()
  openNext()

MosaicPage
  openList()
  filterByDate()

DraftPage
  openDraft()
  submitNext()
  submitPublish()

NotFoundPage
  showMissing()

От страниц пунктир к Домену DendroScalePatterns
(страницы ходят в SSR-обработчики, а SPA потом будет в API).


================================================================
ПОРЯДОК НА ЛИСТЕ А4 СВЕРХУ ВНИЗ
================================================================
1. Postman
2. два интерфейса-кружка
3. рамка Веб-сервис с двумя доменами
4. рамка Модель с тремя классами
5. рамка База данных с тремя таблицами

Не пиши названия на стрелках. Не ставь 1 и * на концах.
)
