Диаграмма классов — шахматно, А4 книжный, ничего не пересекается
================================================================
Верхняя полоска КАЖДОГО класса: заливка #1c1c1c, шрифт имени БЕЛЫЙ.
Нижняя полоска: белая, операции или атрибуты чёрным.
Шрифт 8 pt. Стрелки без подписей и без 1/*.


ШАХМАТНАЯ СЕТКА (не ставь всё в один столбец)

Ряд 0. Четыре страницы — классы с ДВУМЯ полосками, 2 клетки × 2 клетки:

   +------------------+     +------------------+
   | FeedPage         |     | MosaicPage       |     <- тёмная, белый текст
   |------------------|     |------------------|
   | +openFeed()      |     | +openList()      |
   | +openNext()      |     | +filterByDate()  |
   +------------------+     +------------------+

   +------------------+     +------------------+
   | DraftPage        |     | NotFoundPage     |
   |------------------|     |------------------|
   | +openDraft()     |     | +showMissing()   |
   | +submitNext()    |     |                  |
   | +submitPublish() |     |                  |
   +------------------+     +------------------+

Страницы чуть левее. Справа от них — клиент и веб-сервис.


Ряд 1. Клиент по центру правой половины:

              +---------+
              | Postman |
              +---------+
                 /   \
          Usage /     \ Usage
               v       v
             ( o )   ( o )
   API DendroScale   API Dendro
      Patterns       Researchers

Кружок = Provided Interface / lollipop. НЕ класс-прямоугольник.
Не пиши внутри кружка длинный текст.


Ряд 2. Домены — два квадрата рядом, не наезжают:

   +---------------------------+  +----------------------+
   | Домен DendroScalePatterns |  | Домен DendroResearchers
   |---------------------------|  |----------------------|
   | +GET  .../patterns        |  | +POST .../register   |
   | +GET  .../feed            |  | +POST .../login      |
   | +GET  .../feed/:id        |  | +POST .../logout     |
   | +GET  .../draft           |  +----------------------+
   | +POST .../patterns        |
   | +PUT  .../publish         |
   | +DELETE .../:id           |
   | +POST .../:id/like        |
   +---------------------------+

От кружка вниз к своему домену: Interface Realization (сплошная, треугольник).


Ряд 3. Модели — три квадрата в шахматку, средний чуть ниже,
чтобы стрелки не пересекались:

   +------------------+          +------------------+
   | Модель           |          | Модель           |
   | DendroResearcher |          | DendroPatternLike|
   |------------------|          |------------------|
   | id               |          | id               |
   | login            |          | researcherId     |
   | password         |          | patternId        |
   | fullName         |          +------------------+
   +------------------+
              +----------------------+
              | Модель               |
              | DendroScalePattern   |
              |----------------------|
              | id title status      |
              | imageUrl videoUrl    |
              | eventYear ringCount  |
              | creatorId            |
              +----------------------+

Пунктир Dependency: домен паттернов → Pattern и Like;
домен исследователей → Researcher.


Ряд 4. Таблицы — три квадрата <<table>>, компактные, как ER:

   +--------------------+     +-------------------------+
   | dendro_researchers |     | dendro_scale_patterns   |
   |--------------------|     |-------------------------|
   | PK id              |     | PK id                   |
   | login password     |     | title status creator_id |
   | full_name          |     | image_url NULL          |
   +--------------------+     | video_url NULL          |
                              | event_year NULL         |
                              | ring_count NULL         |
                              +-------------------------+
                 +------------------------+
                 | dendro_pattern_likes   |
                 |------------------------|
                 | PK id                  |
                 | FK researcher_id       |
                 | FK pattern_id          |
                 +------------------------+

Пунктир модель → своя таблица. Между таблицами сплошная без 1/*.


КАК УБРАТЬ ПЕРЕСЕЧЕНИЯ
1. Включи Snap to Grid.
2. Между рядами пустая полоса высотой с один класс.
3. Не тяни длинные диагонали через весь лист: сначала вниз, потом вбок
   (Rectilinear / orthogonal в StarUML).
4. Страницы только слева, сервис справа. Модели не клади под страницами
   в ту же клетку.


ИНТЕРФЕЙСЫ «НОРМАЛЬНО»
Toolbox → Interface (кружок) ИЛИ Port + Provided Interface.
Имя кружка: API DendroScalePatterns / API DendroResearchers.
Postman  --Usage-->  кружок  --Realization-->  класс домена.
Не рисуй интерфейс как третий большой класс с методами — методы только
у домена.
