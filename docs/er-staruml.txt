ER для StarUML — Dendro Age
============================
Три КВАДРАТА, компактно, в одну линию researchers — patterns,
likes чуть ниже между ними. Не растягивай на весь лист.

Линии СПЛОШНЫЕ. Имя связи пустое. Без 1 и *.
Delete = Restrict.


ЧТО ОБЯЗАТЕЛЬНО ПОСЛЕ INSERT ЧЕРНОВИКА
--------------------------------------
Проверка в Adminer сразу после создания карточки
(кнопка Далее или POST /api/dendro_scale_patterns):

ОБЯЗАТЕЛЬНЫЕ (NOT NULL, пустыми не бывают):
  id            — выдаёт база
  title         — название, его вводят
  status        — ставит сервер: draft
  created_at    — ставит сервер
  creator_id    — ставит сервер, singleton shebe

ЧЕТЫРЕ НЕОБЯЗАТЕЛЬНЫЕ ГРУППЫ в услуге (паттерне) — в таблице NULL:

  1. URL             image_url, video_url
  2. Поля по теме    event_year, ring_count
  3. Описание        short_description, full_description
  4. Дата формы      formed_at

После INSERT черновика в Adminer эти ячейки именно NULL, не 0 и не "".

Что обязательно ГДЕ:
  В таблице после INSERT: title, status, created_at, creator_id.
  URL в таблице НЕ обязательны (файлы могут не прийти, тогда дефолт на SSR).
  Поля по теме в таблице НЕ обязательны; в методе PUT publish — обязательны.
  Краткое описание в таблице НЕ обязательно; в методе PUT publish — обязательно.
  Полное описание нигде не обязательно.


ТАБЛИЦА dendro_researchers
--------------------------
id          PK   BIGINT        обязательно
login       UQ   VARCHAR(64)   обязательно
password         VARCHAR(128)  обязательно
full_name        VARCHAR(128)  обязательно


ТАБЛИЦА dendro_scale_patterns
-----------------------------
id                  PK   BIGINT         обязательно
title                    VARCHAR(160)   обязательно
short_description        VARCHAR(500)   NULL
full_description         VARCHAR(2000)  NULL
status                   VARCHAR(20)    обязательно
image_url                VARCHAR(255)   NULL
video_url                VARCHAR(255)   NULL
event_year               BIGINT         NULL
ring_count               BIGINT         NULL
created_at               TIMESTAMPTZ    обязательно
formed_at                TIMESTAMPTZ    NULL
creator_id          FK   BIGINT         обязательно  -> dendro_researchers.id


ТАБЛИЦА dendro_pattern_likes
----------------------------
id              PK   BIGINT   обязательно
researcher_id   FK   BIGINT   обязательно  -> dendro_researchers.id
pattern_id      FK   BIGINT   обязательно  -> dendro_scale_patterns.id
пара (researcher_id, pattern_id) уникальна


КАК ПОПРАВИТЬ УЖЕ НАРИСОВАННУЮ ДИАГРАММУ
----------------------------------------
1. Кликни каждую связь. Поле Name очисти.
2. Убери подписи кардинальности 1 и * (Cardinality поставь пустым или скрой).
3. Линия должна быть сплошной.
4. У колонок паттерна из списка NULL включи Nullable.
5. В dendro_researchers добавь password VARCHAR(128), Nullable выключен.
6. Для скрина в Adminer выполни:

SELECT id, title, status,
       image_url, video_url,
       short_description, full_description,
       event_year, ring_count, formed_at
FROM dendro_scale_patterns
WHERE status = 'draft';

На фото у черновика URL, описания и поля по теме — пустые ячейки NULL.
